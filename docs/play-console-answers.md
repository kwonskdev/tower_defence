# 구글 플레이 콘솔 설문 답안 - 멀티플레이 출시용 (#27)

콘솔은 코드로 입력할 수 없어서 **소유자가 멀티플레이 배포와 같은 시점에** 아래대로 입력한다 (먼저 바꾸면 거짓 신고, 늦으면 정책 위반).
근거는 코드와 `docs/accounts-and-db.md` 6절이다. 콘솔 문구는 바뀔 수 있으니 항목 이름이 다르면 가장 가까운 것을 고른다. **[출시 직전 확인]** 표시는 소유자가 결정/확인할 부분이다.

## 1. 데이터 보안(Data safety)

**수집/공유 개요**
| 질문 | 답 |
|---|---|
| 앱이 필수 사용자 데이터 유형을 수집하거나 공유하나요? | **예** (멀티플레이 때문에) |
| 전송 중 데이터가 암호화되나요? | **예** (`wss://`, TLS는 Cloudflare. 릴리즈 빌드는 평문 연결을 막는다) |
| 사용자가 데이터 삭제를 요청할 수 있는 방법이 있나요? | **예** (앱의 [데이터 삭제 요청] 링크 + 웹 양식) |
| 삭제 요청 웹 링크 | **[출시 직전 확정]** 웹 양식이 없으므로 이메일 요청 방법이 적힌 방침 웹 페이지 주소를 넣는다 |
| 계정 만들기 방식 | 앱 계정(익명, 사용자 ID/비밀번호 입력 없음). 계정 삭제 요청 URL은 위 웹 링크 |

**데이터 유형별** (수집됨 / 공유 안 함 / 모두 필수 / 용도 앱 기능·계정 관리)
| 범주 > 유형 | 수집 | 공유 | 선택/필수 | 용도 | 근거 |
|---|---|---|---|---|---|
| 개인 정보 > **사용자 ID** | 예 | 아니요 | 필수 | 앱 기능, 계정 관리 | 계정 ID(무작위)와 토큰 해시 |
| 개인 정보 > **이름**(닉네임 입력) | **[출시 직전 확인]** 예 권장 | 아니요 | 필수 | 앱 기능, 계정 관리 | 이용자가 정한 닉네임. 콘솔에서 "이름"에 해당하는지 애매하므로 보수적으로 예(기타 정보로 신고해도 됨) |
| 앱 활동 > **기타 사용자 생성 콘텐츠 / 앱 활동** | 예 | 아니요 | 필수 | 앱 기능, 분석 아님 | 판 기록(결과, 도달 단계, 피해량) |
| 기기 또는 기타 ID > 기기 ID | **아니요** | - | - | - | 광고 ID/기기 ID 안 씀 (계정 토큰은 앱이 만든 값) |
| 앱 정보 및 성능 > 비정상 종료/진단 | **아니요** | - | - | - | SDK 없음. 서버 로그는 닉네임/연결 번호만 |
| 위치, 연락처, 사진, 오디오, 결제 정보, 건강, 메시지(채팅) | **아니요** | - | - | - | 채팅/이모트 제외 |

- **IP 주소**: 서버 코드는 저장하지 않는다. 단 Cloudflare 터널이 중계하며 자체적으로 처리할 수 있다. Cloudflare를 "서비스 제공자(처리자)"로 보면 공유 아님(처리 위탁으로 신고 안 함)이 일반적이지만, 정확한 구분은 Play 정책 문구를 보고 정한다.
- "수집 후 서버로 전송되고 **임시로만 처리**" 예외는 해당 없음 (계정/기록은 저장된다).
- 데이터는 사용자 요청 시 삭제 가능으로 신고, 보관 기간은 방침과 같게 (계정+판 기록 마지막 접속 후 365일, 로그 30일, 삭제 요청 후 30일 내 파기).
- 광고/분석/제3자 SDK 없음 -> "제3자와 공유" 항목은 모두 아니요.

## 2. 콘텐츠 등급 설문 (IARC)
| 질문 | 답 |
|---|---|
| 카테고리 | 게임 |
| 폭력 | 판타지 폭력, 경미함 (타워/몬스터. 피 표현 없음 **[확인: 스크린샷 기준]**) |
| 성적 콘텐츠, 욕설, 약물, 도박(실제 돈/모의 도박) | 모두 아니요 |
| **사용자 간 상호작용 / 사용자 생성 콘텐츠 공유** | **예**: 온라인에서 다른 사용자와 함께 플레이하고 **닉네임**이 다른 사용자에게 보인다. 채팅/음성/이모트/이미지 공유는 **없다** (질문이 "사용자 간 통신 가능"이면 "제한적: 닉네임만, 자유 텍스트 대화 없음"으로 답한다) |
| 위치 공유 | 아니요 |
| 디지털 상품 구매 | 아니요 |
| 신고/차단 | 닉네임 금칙어 필터(서버), 신고는 앱의 [닉네임 신고] 링크(이메일), 운영자가 계정 차단 |

예상 등급은 설문 결과로 정해진다 (온라인 상호작용 표시가 붙을 수 있음).

## 3. 광고, 앱 내 구매
- 광고 포함: **아니요** (광고 SDK 없음)
- 앱 내 구매: **아니요**. 무료 앱.
- 유료/가격: 무료.

## 4. 그 밖에 콘솔에서 맞출 것
- **앱 액세스**: 로그인 없이 모든 기능 이용 가능 (익명 계정 자동 생성). 온라인 판은 서버가 켜져 있어야 하므로, 심사자가 확인할 수 있게 서버를 켜 두고 안내를 쓴다. **[출시 직전 확인]**
- **대상 연령**: 13세 이상으로만 설정한다(소유자 결정). 방침 10절과 같다. 아동 대상 앱이 아님.
- **권한**: 앱 매니페스트의 권한은 `INTERNET`뿐이다.
- **사용자 생성 콘텐츠(UGC) 정책**: 닉네임만 있고 채팅이 없어 신고/차단 요구는 닉네임 신고 링크와 금칙어로 충족한다고 신고한다. 채팅/이모트를 넣게 되면 다시 검토한다.
- 방침 URL: `docs/multiplayer-release-store-listing.md` 끝 항목과 같은 주소.
