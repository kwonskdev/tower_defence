# 스토어 설명 - 멀티플레이 출시용 초안 (#27)

> **아직 적용하지 않는다.** 멀티플레이를 실제로 배포할 때 소유자의 로컬 `store-listing.md`(git에 올리지 않는 개인 메모)와 Play Console 입력란에 아래 문구를 옮긴다.
> 지금 코드로 동작이 확인된 것만 썼다: 협력(PvE) 최대 8명, 방 코드/빠른 시작, 판 중 재접속, 익명 계정과 판 기록. **PvP, 채팅, 이모트, 순위 화면, 구글 로그인은 쓰지 않는다** (순위는 서버 조회만 있고 화면이 없다).
> `store-listing.md`의 옛 줄 "인터넷 연결 없이 플레이 (개인정보 수집 없음)" 과 태그 "오프라인"은 아래처럼 바꿔야 한다 (그대로 두면 거짓 설명).

## 짧은 설명 (80자 이내)
타워로 길을 만들고 몬스터를 보내 보스를 쓰러뜨리는 레인 디펜스, 최대 8명 협력

## 전체 설명에서 바꿀 부분

**추가: 멀티플레이 섹션** ("핵심 특징" 위나 아래에 넣는다)
```
### 친구와 함께 (협력 멀티플레이)
- 최대 8명이 한 팀이 되어 같은 보스에 맞서는 협력 모드
- [방 만들기]로 방 코드를 받아 친구에게 알려 주거나, [빠른 시작]으로 바로 한 판
- 각자 자기 레인에 타워를 짓고 몬스터를 보내 함께 보스를 공격
- 판 도중 연결이 끊겨도 다시 들어와 이어서 할 수 있어요
- 닉네임으로 참여합니다 (회원가입 없음). 판 기록이 닉네임과 함께 서버에 저장됩니다
- 온라인 멀티플레이는 인터넷 연결이 필요해요. [혼자 하기]는 인터넷 없이도 됩니다
```

**바꿀 줄 ("기타" 섹션)**
- 삭제: `인터넷 연결 없이 플레이 (개인정보 수집 없음)`
- 교체: `혼자 하기는 인터넷 없이 플레이 / 온라인 멀티플레이는 인터넷 필요 (닉네임과 판 기록 저장, 개인정보처리방침 참고)`
- 유지: `무료, 광고 없음, 인앱 결제 없음`

**"게임 방법" 1번 앞에 한 줄**: `혼자 하거나, 방 코드로 친구와 모여 시작합니다.`

## 태그
`타워 디펜스, 전략, 협동` (오프라인 태그는 빼거나 "싱글 플레이"로 바꾼다)

## 개인정보처리방침 URL
방침 페이지(`docs/multiplayer-release-privacy-policy.html` 내용)를 웹에 올린 주소를 입력한다. 같은 주소를 앱의 `MainMenu.PRIVACY_POLICY_URL`에도 넣는다.

## 출시 체크리스트에 추가 (로컬 store-listing.md)
- [ ] 방침 URL이 새 방침(멀티플레이)을 가리킨다
- [ ] 위 전체 설명/짧은 설명/태그를 옮겼다 (서버가 실제로 열린 뒤에)
- [ ] Play Console 데이터 보안, 콘텐츠 등급 설문을 `docs/play-console-answers.md` 대로 다시 제출했다
